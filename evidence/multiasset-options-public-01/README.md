# Finite uncapped ETH/SOL and empty PAXG verification

One finite 75-second public Deribit testnet capture discovered/selected all 804 ETH and 142 SOL options. All 2,840 native registry channels acknowledged in 29 batches, with one full session and zero disconnects. PAXG returned no options and remains `OPTION_SELECTED_UNIVERSE_EMPTY`; no synthetic gold route was enabled. It saved 47,756 unique rows and pending outbox entries, then stopped. Discovery and shutdown add wall time.

At the saved final as-of check all 804 ETH tickers, 646 ETH books and 142 SOL tickers pass both 30-second bounds. There are 158 stale ETH and 142 stale SOL books, with no missing populated-chain legs. `age-proof.json` verifies both source and receipt bounds fail for every stale book, and records exact age ranges and signed clock differences. Some source times are ahead of local receipts; this is not negative wire latency, and no cause is inferred. No native timestamps or bounds were altered.

`independent-proof.json` verifies all 946 metadata bindings, exact shared subscription/native index channels, 29 timing partitions, 68 SQL control/PIT boundaries, six ack visibility checks and 1,892 independent SQL latest-leg selections. Duplicate replay, pending outbox, sealed Parquet/database equality, closed reload and original-byte preservation passed. Derived replay artifacts are in `../multiasset-options-replay-01`. Both saved verifiers make zero network requests, require fresh report/output artifacts and refuse overwrites.

`verifier_used.py` is the exact script used for this public capture. Its original aggregate flag spelling `all_requested_nonempty_universes_acknowledged` meant every requested asset must have nonempty acknowledged membership, so PAXG makes it false. The released script clarifies this with `every_requested_asset_has_nonempty_acknowledged_universe`. Original saved reports remain byte-identical. Separate BTC evidence is in `../reused-validation-public-01`; this is not one simultaneous four-asset or seven-day run. Every native option field, trade continuity, all-feed completion and trading approval remain unverified. No private API, orders or production execution occurred.
