It replays 62,089 original BTC and 47,756 original ETH/SOL/PAXG rows into independent derived stores, preserves original identities/values/clocks and compares every asset's final view plus 20 control/PIT boundaries against the unchanged full-row canonical oracle and saved reports. Materialized final totals are BTC 3,033, ETH 2,415, SOL 429 and PAXG 3. Stale books and empty gold stay blocked; no freshness or timestamp changes occur.

A clearly labelled synthetic test adds 110,000 old ticker records carrying `fixture_origin=SYNTHETIC_OLD_QUOTE_HISTORY_NOT_PUBLIC`. It is not downloaded history or a sustained run. All 172,089 BTC native/fixture rows remain in storage/outbox, while the old full-row view exceeds its unchanged 100,000-row budget. The new projection materializes the same 3,033 rows and matches the original native view exactly. Every original row is an exact SQL-selected subset, and native baseline/final fixture archives match storage; closed reload, replay deduplication and all twelve original source-file hashes pass.

The projection preserves all latest source/receipt ties and all eligible scoped metadata/controls, sharing one bounded Python fetch budget plus one overflow sentinel. SQL may scan retained history, and database size/engine memory/query time and metadata/control generations are not certified bounded. This is not sustained capacity or M2 completion.
