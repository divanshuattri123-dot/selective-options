Zero public requests. Real SpotTradeCollector, EventBus, production consumer and DuckStore replay55 saved Kraken BTC native trade events from live-gap-02. Original frame bytes and boundaries were not archived, so input containers are explicitly reconstructed. Two fresh collectors process contiguous cohorts50and5 separated across missing WS trade109230677; no REST row is converted to WS and no cross-gap continuity is claimed. Native fields, IDs, source clocks and original receipts remain exact. Derived status/bar rows use explicitly synthetic offline clocks and are mapped by event ID. A two-trade synthetic update whose later trade is below a finalized watermark emits zero rows and preserves collector state and storage; its valid successor is then accepted and independently aggregated. OHLC, Decimal volume/count, closed bars, both-clock PIT, sealed archive and exact pending outbox membership are checked. This is not original-frame replay, atomic sink commit, public collection, Redis delivery, complete history or seven-day validation.
